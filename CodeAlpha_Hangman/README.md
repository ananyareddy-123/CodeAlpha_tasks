# Hangman Game

## Overview
A classic text-based Hangman game implemented in Python where players guess letters to reveal a hidden word within a limited number of incorrect attempts.

## Features
- Random word selection
- Tracks correctly guessed and wrong letters
- Visual feedback on remaining guesses

## How to Run
```bash
python HangmanGame.py
